# Shared agent memory

Several AI agents work for the same person. This folder lets what one agent learns reach the others, and decides who writes the formal knowledge base. Every agent reads this file, `conventions.md`, `authorization.md` and `focus.md` before starting work.

## Three layers

| Layer | Where | Who writes | What goes in |
|---|---|---|---|
| Native memory | each agent's own memory feature | that agent | working state that only matters to itself |
| Shared memory | `agents/<agent>/memory/` and `agents/<agent>/return/` | each agent writes only its own folder, everyone reads all | corrections, tool gotchas, project notes, return cards |
| Formal knowledge base | `kb/` | one promoter agent only | confirmed facts, decisions, definitions, procedures |

How to pick a layer:

1. A different agent doing this task next week would need it: write at least shared memory.
2. The human decided something, a number's definition changed, or an old KB statement is now wrong: write a return card and let the promoter move it into `kb/`.
3. Intermediate state of this one task: keep it in native memory.

## Layout

```
agents/
  _shared/            maintained by the promoter only
    README.md         this file
    conventions.md    signatures, memory entry format, return card format
    authorization.md  what each agent may do without asking
    focus.md          this week's priorities, mirrored from the promoter's memory
    progress.md       generated by agent_handoff.py, one row per session
    progress/         index.json and lock, machine use
  Claude/memory/      read-only mirror of Claude's native memory
  Codex/memory/       Codex lessons, extracted nightly
  <agent>/memory/     one file per fact
  <agent>/return/     return cards waiting for promotion
kb/                   formal knowledge base
```

## Picking up someone else's work

Run `agent_handoff.py recent <keyword>` first. It answers in under a second. If a row matches, `agent_handoff.py show <ID>` prints every message the human sent in that session, the last conclusion and the files written. Read those files and continue. Do not ask the human to repeat themselves, and do not read whole transcripts or whole folders.

No earlier work implied? Skip the lookup. Speed matters more than completeness.

## What the promoter does each night

1. Mirror its own native memory into `agents/<promoter>/memory/` and copy the focus file to `_shared/focus.md`.
2. Extract new Codex lessons into `agents/Codex/memory/`.
3. Go through every return card with `status: pending`. Cards marked "decided by the human" are promoted into `kb/` directly. "Leaning" or "my inference" cards are promoted only when the evidence is attached, otherwise they go to a review queue. Set the card to `status: merged` and note where it went.
4. Merge feedback that holds for every agent into `conventions.md`.

## Never

1. Edit another agent's `memory/` or `return/`.
2. Edit `_shared/` unless you are the promoter. Found a mistake there? Say so in your own return card.
3. Write to `kb/` unless you are the promoter.
4. Store secrets. Write where a credential lives, never the value.
