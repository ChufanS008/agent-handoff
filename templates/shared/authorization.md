# Authorization tiers

Three tiers. Check this table before any action you are unsure about. When an upgrade condition is met, propose the upgrade to the human. Never move yourself up a tier.

| Tier | Meaning |
|---|---|
| Read | look, search, summarize |
| Low-risk write | reversible and stays inside the machine or a private draft |
| High-risk | visible to other people, or hard to undo. Every instance is proposed, approved, then executed |

| Channel or tool | Tier | Allowed without asking | Always ask | Upgrade condition |
|---|---|---|---|---|
| Email | Low-risk write | drafts, labels, search | sending, replying, forwarding | a fixed sequence of drafts goes 4 weeks with zero edits |
| Team chat, direct message to the human | High (opened) | scheduled reports and alerts | | |
| Team chat, group channels | Low-risk write | only channels and templates a task names | new channels, new message types, mentions | a new message type is approved twice unchanged |
| Docs and spreadsheets | Low-risk write | create, append | delete, clear, change sharing | |
| Public posting, publishing, bulk email | High-risk | draft only | every publish | never |
| Memory, rule files, skills | Low-risk write | create, edit, with an audit line | bulk delete, editing this table | |
| Scheduled jobs, hooks, system config | Low-risk write | create, edit, with an audit line | delete jobs, irreversible settings | |
| Payments, trades, credentials | Forbidden | | everything | never |

Edit the rows to match your tools. Keep the shape: what is allowed, what always needs a yes, and what evidence would earn an upgrade.
